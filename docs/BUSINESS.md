# Business Model & SKUs

AIFoundry.sh provides prepaid, metered API capabilities for autonomous AI agents and developers.

## SKUs

| SKU | Price | Allowance | Margin |
|---|---|---|---|
| **T10K** | $0.05 USDC | 10,000 input tokens / 10,000 output tokens | ≥ 3x COGS ($0.05 list vs ~$0.015 vendor cost) |
| **M10** | $0.05 USDC | 10 minutes wall clock execution budget | ≥ 3x COGS |

## Margin Rule
List price is strictly set to ≥ 3x vendor cost at the token cap.
Clients never hold vendor API keys (DeepSeek / Nemotron / Kimi). All upstream calls are executed via the gateway using operator secrets.
