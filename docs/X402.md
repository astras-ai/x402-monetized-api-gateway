# x402 Protocol Specification & Facilitator Integration

AIFoundry.sh implements the HTTP 402 Payment Required specification.

## Unpaid Response (HTTP 402)
```http
HTTP/1.1 402 Payment Required
Content-Type: application/json
X-402-Price: 0.05
X-402-Currency: USDC
X-402-Network: base-sepolia
X-402-Facilitator: https://x402.org/facilitator

{
  "error": "Payment Required",
  "status": 402,
  "x402": {
    "version": "1.0",
    "price": "0.05",
    "asset": "USDC",
    "network": "base-sepolia",
    "payToConfigured": true
  }
}
```
